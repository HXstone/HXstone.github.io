Case study

Case 01
Problem

I wanted a game with real decisions, not just reflexes — one where you cannot win everything.

Thinking

Each hour can only be spent once. If studying always paid off there would be no game — the tension comes from the cost.

Solution

Seven actions, five visible stats, warnings and limits when one runs low, weighted events, and a rating at the end of each 14-day cycle.

Technology

Hand-written HTML, CSS and JavaScript, with the event library split from the engine; saves and records live in localStorage.

Result

About 90 KB with no dependencies. It runs in the browser and keeps a record of every cycle you finish.

Case study

Case 02
Problem

The original board is fiddly on a phone, and one careless tap ends the whole round.

Thinking

I wanted “familiar but friendlier”: the same rules I grew up with, on a board that forgives a beginner.

Solution

Three difficulty levels, a timer, bigger tap targets, and a first tap that is always safe.

Technology

HTML, CSS and JavaScript. AI was my pair programmer; I played every round and asked for the changes.

Result

Runs smoothly on mobile and desktop, and it is live on this site — open it and try a round.

Case study

Case 03
Problem

The original is fun for thirty seconds, and then never changes again.

Thinking

I wanted a run that grows with the player: busier obstacles, and a smoother nightfall.

Solution

Jump, duck and fast-fall, a scrolling day-night cycle, and controls that work on keyboard and touch.

Technology

A single HTML file with a self-scaling canvas — no libraries, no build step.

Result

About 27 KB. It opens instantly, even on a slow phone.

Case study

Case 04
Problem

I wanted a game visitors could understand in seconds, but still keep playing for a high score.

Thinking

Classic tank controls are instantly familiar; destructible terrain makes each round feel different.

Solution

Drive, shoot, use cover, and survive three lives against increasingly busy enemy patrols.

Technology

One responsive Canvas game with generated sound effects and touch controls—no assets or libraries.

Result

Playable on desktop and mobile, with the best score saved locally for the next visit.
