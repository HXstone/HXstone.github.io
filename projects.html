Selected Work

Three real things I built. Each one started with a problem and ended when it was playable or usable.

Minesweeper

A 1990s classic, rebuilt for my own phone: a dark board, a safer first tap, and three levels.

Open the game →
Problem

The original board is fiddly on a phone, and one careless tap ends the whole round.

Thinking

I wanted “familiar but friendlier”: the same rules I grew up with, on a board that forgives a beginner.

Solution

Three difficulty levels, a timer, bigger tap targets, and a first tap that is always safe.

Technology

HTML, CSS and JavaScript. AI was my pair programmer; I played every round and asked for the changes.

Result

Runs smoothly on mobile and desktop, and it is live on this site — open it and try a round.

Dino Run

The offline dino game, but with a difficulty curve and a day that actually turns into night.

Open the game →
Problem

The original is fun for thirty seconds, and then never changes again.

Thinking

I wanted a run that grows with the player: busier obstacles, and a smoother nightfall.

Solution

Jump, duck and fast-fall, a scrolling day-night cycle, and controls that work on keyboard and touch.

Technology

A single HTML file with a self-scaling canvas — no libraries, no build step.

Result

About 27 KB. It opens instantly, even on a slow phone.

Mistake Notebook

A second brain for the mistakes I keep repeating, organised by subject and topic.

In progress See the notes
Problem

Mistakes live on paper: scattered, unsearchable, and impossible to review before a test.

Thinking

If a note cannot be found in five seconds, it will never be reviewed.

Solution

Markdown notes per subject and topic, each one tagged with the cause of the mistake.

Technology

Plain text and Git, so every change is tracked.

Result

Work in progress — a searchable online version is the next step.
